About 3GS

What it is

Three Good Sources is a small, human-curated registry that answers one question for AI agents: "where should I learn about this?" Each topic gets exactly three sources, ranked, with a short note on why each one is there. Agents reach it over MCP; people can read the same data as JSON at /registry.

How curation works

A curator researches a topic, picks three sources, ranks them, and writes down why. Each topic also lists the plain-language questions people actually ask, so agents can match "how do I run a bitcoin node" to the right entry. Everything lives in a single registry.json file; its format is described in SCHEMA.md.

Every change to the registry is recorded in an append-only audit log, so you can see what was added or replaced, and when.

How signing works

The curator is identified by an Ed25519 key (a PKARR public key), not an account. The registry file carries a signature made with that key, and each audit log entry is signed and linked to the one before it by hash. The server refuses to start with a registry that doesn't verify, peers check it on every fetch, and anyone can check it themselves. A valid signature shows who published the registry and that nobody changed it since. It does not prove it is the newest version.

Step-by-step verification is in PUBKY.md.

Fork it, run your own

3GS is meant to be one node among many. Anyone can run a server with their own registry and their own key, specialize in the topics they know, and endorse other curators they trust. A node then answers from its own registry and, for federated queries, from the signed registries of the curators it endorses. 

cargo run -- fork --endorse <curator-pubkey> --url <curator-url> --name "Your Name"

This scaffolds a new node with a fresh keypair and a signed starter registry. Add your topics, re-sign, and deploy. See the README for details.
